# Petit Tonnerre - Gestionnaire d'Entretien Domestique

## Description du Projet

Application permettant aux utilisateurs de gérer l'entretien de leurs objets et appareils domestiques de manière intelligente et collaborative.

## Fonctionnalités Principales

### 1. Gestion des Objets

- Inventaire des objets/appareils domestiques
- Création de "cartes d'identité" pour chaque objet
- Liaison avec les manuels d'utilisation
- Exemples d'objets supportés : chaudière, four, pierre bleue, appareils électriques, sanitaires

### 2. Système de Maintenance

- Notifications régulières pour les tâches d'entretien
- Conseils d'entretien personnalisés
- Suivi des tâches effectuées
- Système de feedback post-entretien
  - Questions sur la réalisation des tâches
  - Identification des problèmes rencontrés

### 3. Aspect Communautaire

- Aide locale entre utilisateurs
- Partage d'expériences et solutions
- Système de validation des contributions
- Structure organisée et modérée (pas de forum ouvert)

### 4. Todo-list Interactive

- Suivi des problèmes non résolus
- Suggestions basées sur les expériences similaires
- Mise en relation avec des utilisateurs ayant rencontré des problèmes similaires

## Objectifs du PoC (Proof of Concept)

1. Interface d'encodage des objets
2. Système de conseils d'entretien
3. Mécanisme de propositions/validation communautaire

## Stack Technique

- Frontend : Angular
- Backend : FastAPI
- Base de données : PostgreSQL
